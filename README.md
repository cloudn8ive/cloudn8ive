### Hi, I'm cloudn8ive

I build cloud infrastructure and AI agent tooling, plus the small utilities that
keep complex systems reliable and easy to run.

**What I work on**
- AI agents and the tooling around them: orchestration, observability, guardrails
- Cloud infrastructure and automation
- Windows and cross-platform utilities, mostly in Go and Python

**Projects**
- [hermes-safe-update](https://github.com/cloudn8ive/hermes-safe-update): a careful
  updater for the Hermes Agent desktop app (Windows; macOS and Linux builds untested).
  It waits for running work, verifies the result, and backs up and migrates desktop
  settings across updates.
